# CyberLab — مختبر الأمن

منصة عربية وإنجليزية بخمس أدوات فعلية لفحص إعدادات الويب، وتحليل الروابط وQR، واستكشاف خصوصية المتصفح، وتحليل السجلات، وإنشاء التقارير. عامة دون حسابات أو لوحة إدارة.

- النسخة الرئيسية: https://cyberlab-ar.connecttag.workers.dev
- النسخة التجريبية: https://cyberlab-ar-staging.connecttag.workers.dev
- موارد مستقلة لكل بيئة: Worker للتطبيق، وWorker خاص للفحص، وD1 للحصص، وعنصر Turnstile مستقل.

## استخدامه كقالب

المصدر: [connecttag/cyberlab-ar](https://github.com/connecttag/cyberlab-ar). يمكنك بدء مستودع مستقل من زر **Use this template** في GitHub.

قبل النشر في حسابك، غيّر أسماء Workers ومعرّف الحساب في ملفَي Wrangler، وأنشئ قاعدتَي حصص وعناصر Turnstile خاصة بك، ثم استبدل معرّفات D1 والمفاتيح العامة وأسماء المضيفين. إعدادات النشر المرفقة تخص نسخة ConnectTag المنشورة. أنشئ أسرارك المستقلة عبر stdin واتبع [دليل النشر](docs/deployment.md)؛ لا تعِد استخدام موارد النسخة الأصلية.

## التشغيل

يتطلب Node.js ≥22.12، ويوصى بـNode 24 LTS. على جهاز التطوير الحالي يوجد Node 22.9 في PATH؛ يوفر `scripts/run.ps1` اختيارًا محليًا لنسخة Node المناسبة الموجودة ضمن runtime الخاص بـCodex دون تغيير إعدادات الجهاز.

```powershell
npm ci
npm run build
npm run db:local
npm run dev:workers
# في نافذة ثانية
npm run dev
```

على Windows يمكن استبدال `npm` بـ`./scripts/run.ps1`، مثل `./scripts/run.ps1 run check`. الواجهة: http://127.0.0.1:5173، وAPI المحلي: http://127.0.0.1:8788. الفحص المباشر مهيأ للنسختين المنشورتين. يتوقف محليًا عند غياب الأسرار أو عدم تطابق المضيف. الأدوات المحلية لا تحتاج أسرارًا أو خدمة API لتعمل.

## الأدوات

1. **فحص الويب:** ترويسات الأمان، Cookies دون قيمها، تحويلات وDNS، وتحليل ترويسات نصية أو استجابات HAR محليًا. يميّز CSP المطبقة عن Report-Only، والسياسات السياقية عن العيوب المثبتة.
2. **الروابط وQR:** تحليل PSL وUnicode/Punycode والمؤشرات البصرية والمعاملات، مقارنة رابطين، وقراءة PNG/JPEG/WebP في Web Worker.
3. **خصوصية المتصفح:** خصائص مباشرة وتقديرية وغير متاحة، دون أذونات حساسة أو بصمات Canvas/WebGL أو اتصال WebRTC.
4. **السجلات:** Combined Log وJSONL مع ربط الحقول والمنطقة الزمنية، قراءة تدريجية داخل Worker، مؤشرات وفلترة وترقيم صفحات وCSV محلي.
5. **استوديو التقارير:** جمع تقارير ومقارنة نسخها، تنقيح ومعاينة، JSON/Markdown/HTML/CSV وطباعة PDF من المتصفح.

توجد أمثلة تشغيلية داخل الأدوات. تستخدم أمثلة السجلات نطاقات IP المخصصة للتوثيق، ولا تمثل نشاط أشخاص حقيقيين.

## البيانات وحدود المعالجة

- السجلات والصور وتحليل الروابط وخصائص المتصفح والاستيراد والتصدير تعالج محليًا.
- الفحص المباشر يرسل الرابط إلى خادم المنصة ثم إلى الموقع المستهدف. لا يُحفظ التقرير أو الرابط في D1.
- D1 مخصص لعدادات حصص مؤقتة بمفاتيح HMAC؛ لا يحفظ IP خامًا أو ملفات أو تقارير. الحذف كل ساعة بعد انتهاء الصلاحية.
- الحفظ المحلي اختياري: حتى 100 تقرير / 25 MiB، وصلاحية 30 يومًا. تخزين المتصفح قابل للإخلاء، لذا نزّل نسخًا مهمة.
- السجلات: 50 MiB أو 200 ألف حدث، 64 KiB للسطر، وعرض 50 حدثًا في الصفحة.
- QR: 10 MiB و16 مليون بكسل. HAR/استيراد التقارير: 8 MiB، وحتى 20 تقريرًا للاستيراد الواحد.
- PWA يخزن موارد التطبيق الثابتة فقط، ويستبعد API والتقارير. يعمل دون اتصال بعد اكتمال تنزيل الموارد.

## التحقق

```powershell
npm run types
npm run typecheck
npm test
npm run build
npm run test:browser
```

اختبارات المتصفح تحتوي سيناريوهات سطح المكتب والهاتف، والترجمة، وQR، والسجلات، والحفظ والتصدير، ومعالجة المدخلات غير الصالحة. ملفات النتائج والصور تحت `output/playwright/` ولا تدخل Git.

اجتاز الإصدار 112 اختبارًا: 72 للمحركات والحماية، و18 داخل Workers وD1، و22 سيناريو متصفح على الحاسوب والهاتف المحاكى. نجح أيضًا فحص example.com داخل خدمة Cloudflare الخاصة. ظهر Turnstile الحقيقي ورفض الرمز غير الصحيح، لكن متصفح الاختبار الآلي لم يحصل على رمز بشري صالح؛ لذلك لا يُسجل المسار الكامل خلف CAPTCHA كاختبار ناجح. التفاصيل والأدلة وحدود التأهيل في [سجل التحقق](docs/verification.md).

## Cloudflare

الموردان `cyberlab-ar` و`cyberlab-ar-scanner` مستقلان عن المشاريع الأخرى. لا يوجد وصول عام إلى Scanner؛ تتصل به البوابة عبر Service Binding. توجد إعدادات staging مستقلة في ملفات Wrangler.

انظر [دليل النشر والتراجع](docs/deployment.md)، و[البنية والخصوصية](docs/architecture.md)، و[قواعد التحليل](docs/rules.md)، و[عقد OpenAPI](docs/openapi.json)، و[سجل التحقق](docs/verification.md).

## حدود النتائج

الفحص يقرأ الاستجابة المرصودة دون تحميل محتوى الموقع أو تشغيل JavaScript أو الزحف أو تسجيل الدخول. لا يدقق انتهاء شهادة TLS أو مجموعات التشفير، ولا يثبت أن التطبيق آمن بالكامل. مؤشرات الروابط والسجلات تحتاج تفسيرًا في سياقها. أمثلة إعداد CSP تبدأ بـReport-Only وتحتاج مراجعة قبل فرضها.

## تراخيص الموارد

خط Tajawal محلي بترخيص SIL OFL داخل `apps/web/public/fonts/OFL.txt`. الأيقونات من Lucide بترخيص ISC. لا تستخدم المنصة خطوطًا أو أيقونات من CDN. تُحمّل Turnstile عند استخدام الفحص المباشر المفعّل فقط، وتخضع خدمات Cloudflare لسياساتها المستقلة.
